**RestoFlow** — открытая двухкомпонентная система автоматизации кафе: от публикации меню и приёма заказа клиентом до приготовления, выдачи, оплаты и аналитики продаж.

> Один код — три контура: десктопное рабочее место персонала, клиентский веб-портал и REST-шлюз с автодокументацией.

---

## 🎯 О проекте

RestoFlow закрывает полный цикл обслуживания гостя кафе:

- 📖 **Меню и стоп-лист** — категории, блюда, временное снятие с продажи без удаления;
- 🛒 **Заказы** — три типа обслуживания (в зале, самовывоз, доставка), канбан-доска этапов приготовления;
- 💳 **Оплата** — тестовый платёжный шлюз с валидацией карты (алгоритм Луна, срок, CVC);
- 🎁 **Лояльность** — 1 балл за 100 ₽ чека, учёт визитов и накопленных сумм;
- 🛟 **Поддержка** — обращения клиентов с двусторонней перепиской и возобновлением закрытых тем;
- ⭐ **Отзывы** — оценки, анонимность по выбору, ответы кафе, витрина со статистикой;
- 🔔 **Уведомления** — клиентские и служебные, почтовый outbox;
- 📜 **Аудит** — журнал всех значимых действий и консоль разработчика с трассировкой запросов.

## 🧩 Компоненты системы

| Компонент | Назначение | Технологии | Порт |
|---|---|---|---|
| **RestoFlow Desk** | Рабочее место персонала: канбан заказов, дашборд KPI, меню, клиенты, поддержка, отзывы, администрирование, аудит | PyQt6 | — |
| **RestoFlow Online** | Клиентский портал: меню с корзиной, трекинг заказа, оплата, профиль с темами, уведомления, поддержка, отзывы | FastAPI + Jinja2 | 8001 |
| **RestoFlow API** | REST-шлюз: JWT-аутентификация, маршруты сервисов, OpenAPI-документация, аудит и dev-логи | FastAPI | 8000 |

### Жизненный цикл заказа

```
новый → готовится → готов к выдаче → подан → оплачен
   │          │
   └──────────┴──→ отменён          (готов к выдаче → оплачен: самовывоз)
```

Переходы контролируются таблицей допустимых транзиций: недопустимое изменение статуса отклоняется с поясняющим сообщением во всех контурах.

## 🧰 Технологический стек

| Слой | Технологии |
|---|---|
| Язык | Python 3.12+ |
| Десктоп | PyQt6, QSS-темизация, нативные анимации виджетов |
| Веб | FastAPI, Uvicorn, Jinja2, CSS-анимации (toast, ripple, reveal) |
| Данные | SQLAlchemy 2.0, SQLite (миграция на PostgreSQL без изменения логики) |
| Безопасность | PyJWT (HS256), SHA-256 + соль, RBAC, HTTP-only cookie, валидация ввода |
| Тесты | pytest (18 тестов: валидация, заказы, биллинг, поддержка, отзывы, администрирование) |

## 🔐 Безопасность

- Хеширование паролей **SHA-256 с индивидуальной солью** (`secrets.token_hex`);
- **RBAC**: роли `admin`, `manager`, `cashier`, `cook`; проверки дублируются на уровне сервисов;
- Клиентские сессии — **HTTP-only cookie** с контролем владения заказом (чужой заказ недоступен даже по прямой ссылке);
- Единый модуль валидации: телефон `+7…`, стойкость пароля (5 критериев), e-mail, адрес, карта по **алгоритму Луна**;
- Журнал аудита всех значимых действий; трассировка запросов заголовком `X-Correlation-ID`;
- Главная учётная запись `admin` защищена от блокировки.

## 🚀 Быстрый старт

### Требования

- Python 3.12+
- ОС Windows 10/11 (или Linux с Qt-зависимостями)

### Установка

```bash
git clone https://github.com/<your-login>/RestoFlow.git
cd RestoFlow
python -m venv .venv
.venv\Scripts\activate            # Windows
pip install -r requirements.txt
python seeds/seed.py              # наполнение БД демо-данными
```

### Запуск (три терминала)

```bash
python -m restoflow.api.main      # REST-шлюз   → http://127.0.0.1:8000/docs
python -m restoflow.web.main      # веб-портал  → http://127.0.0.1:8001
python -m restoflow.desk.main     # десктоп     → окно RestoFlow Desk
```
